1 · COLLEGAMENTO A GITHUB

Non collegato.
Come creo il token? (2 minuti)
  1. Su GitHub apri Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Nome: dex-admin. Scadenza: dopo la festa (es. 30 giorni).
  3. Repository access → Only select repositories → scegli il repository del dex.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Genera, copia il token e incollalo qui sopra.

2 · IMPOSTAZIONI GENERALI

Soglia più bassa = più severa (meno scambi di persona, ma più "non riconosciuto"). Consigliato 0.45–0.55.

3 · CARICAMENTO FOTO IN BLOCCO

Trascina qui tutte le foto insieme, chiamate col nome della persona: marco_1.jpg, marco_2.jpg, luca 1.jpg, Luca Bianchi (3).jpg… Ogni foto viene assegnata alla persona giusta. Se manca una foto scheda, ne viene creata una centrata sul volto.
